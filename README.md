# ✨ Астрель

VK Mini App на стыке **астрологии и Таро**. Главная фишка — расклады Таро трактуются через призму натальной карты пользователя.

> Позиционирование: «для развлечения и самопознания».

## Что внутри

- **Бэкенд:** FastAPI (Python) + Swiss Ephemeris (расчёт натальной карты).
- **База:** SQLite (пользователи и их друзья/партнёры).
- **Фронтенд:** статичная страница `index.html` (VK Bridge), которую отдаёт сам бэкенд.
- **HTTPS:** Caddy (автоматический SSL).

## Структура

```
main.py            # FastAPI: маршруты + расчёт натальной карты
database.py        # подключение к SQLite
models.py          # таблицы: User, Relative
index.html         # форма (фронтенд), отдаётся с "/"
requirements.txt   # зависимости Python
deploy/
  astrel.service   # systemd-сервис (бэкенд работает в фоне)
  Caddyfile        # конфиг Caddy (HTTPS-реверс-прокси)
```
